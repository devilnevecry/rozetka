# Changelog

## [0.1.0] - 2026-11-20

### Added
- Initial release of Rozetka PC power consumption tracker.
- Real-time monitoring of CPU, GPU, RAM, disks, network, temperatures.
- Per-component power estimation (TDP x load) with editable TDP.
- Session and boot cost accounting based on configurable tariff.
- Persistent history (SQLite) with totals.
- PySide6 desktop UI with dashboard, components, history, settings.
